# Как опубликовать профиль

1. Создайте на GitHub публичный репозиторий с именем, которое **точно совпадает** с вашим GitHub username.
2. Скопируйте в него всё содержимое этой папки и отправьте в ветку `main`.
3. В `README.md` замените:
   - `CONTACT_EMAIL` — на адрес электронной почты;
   - `CONTACT_TELEGRAM` — на username без `@`;
   - `CONTACT_WHATSAPP` — на номер в международном формате, только цифры;
   - `CONTACT_DISCORD_ID` — на числовой Discord User ID.
4. Откройте вкладку **Actions**, выберите **Update profile activity** и нажмите **Run workflow**.

После первого запуска `assets/activity.svg` заполнится реальными данными. Затем карточка будет обновляться автоматически раз в неделю.

## Приватные contributions

Стандартный `GITHUB_TOKEN` надёжно видит публичные данные. Если в общую цифру должны входить приватные contributions, создайте fine-grained personal access token с минимально необходимым read-only доступом и сохраните его в секрете репозитория `PROFILE_TOKEN`. Никогда не вставляйте токен прямо в README или workflow.

## Встроенный radar GitHub

Дополнительно включите нативный график на странице профиля: **Contribution settings → Activity overview**. Он будет показан ниже contribution calendar независимо от карточки в README.

## Если нужна GIF-шапка

Текущая шапка уже анимирована средствами SVG и не требует GIF. Для более кинематографичной версии подойдёт короткий бесшовный loop на 6–8 секунд: тёмный терминал, набор трёх строк JavaScript, вывод `Hello, World!`, лёгкий cyan/violet glow без резких вспышек. Рекомендуемая ширина — 1200 px, итоговый файл желательно держать меньше 5 MB.
